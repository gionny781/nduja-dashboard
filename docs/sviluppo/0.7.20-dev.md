# 0.7.20-dev — Accessi in Sicurezza
Prima: `0.7.19-dev` · File in più: pages/sicurezza.js, pages/auto.js (doppio tocco di conferma), edit.js

**Problema segnalato da Giovanni:** in Sicurezza non si possono aggiungere cancello carraio, cancelletto, porta del garage e simili, perché ＋ Aggiungi accetta solo lock, allarmi e sensori. Molti accessi in Home Assistant sono invece cover (device_class gate/garage/door), switch, button, input_button o script.

- Nuova scheda **«🚪 Accessi»** in Sicurezza.
  - Ci finiscono da sole le cover gate/garage/door e le serrature.
  - Con ＋ Aggiungi si inserisce qualsiasi lock, cover, switch, button, input_button o script. Per ognuno si sceglie:
    - nome e icona: cancello, cancelletto, garage, portone, porta;
    - comando: apri/chiudi, impulso, oppure apri-stop-chiudi per le cover;
    - un sensore facoltativo (binary_sensor) che dice se è aperto.
- Pulsanti grandi; per aprire serve il doppio tocco di conferma, come nella pagina Auto.
- Mostra lo stato quando è noto: aperto, chiuso, in movimento.
- Con ✏️ gli accessi si tolgono, si rinominano e si riordinano.
- In Home una scheda compatta «Accessi» con i pulsanti principali, tramite `HOME_EXTRA`, solo se ci sono accessi.
