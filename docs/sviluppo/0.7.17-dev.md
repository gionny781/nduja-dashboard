# 0.7.17-dev — Elettrodomestici animati
Prima: `0.7.16-dev` · File in più: pages/elettrodomestici.js, pages/home.js, pages/mappa.js, edit.js

Per ogni elettrodomestico (lavatrice, asciugatrice, lavastoviglie, forno, frigo…) con ✏️ si sceglie l'aspetto per **fermo**, **in funzione** e **finito**:

1. **Le mie immagini**: un indirizzo per ciascun momento, con un'immagine o GIF dell'utente, di solito in `/config/www`, quindi `/local/…` (Giovanni ha già le sue così).
   - Suggerimento `/local/…` nel campo.
   - Anteprima.
   - Controllo che il file esista (fetch HEAD), con un avviso se manca.
2. **Animazioni della plancia**: disegnate **da te** in SVG + CSS, belle e moderne, nello stile vetro. Almeno queste:
   - lavatrice e asciugatrice: oblò che gira, bolle, acqua;
   - lavastoviglie: vapore e spruzzi;
   - forno: resistenze che si scaldano, luce;
   - frigo;
   - una generica per le prese.
   Ognuna ha la versione ferma, quella animata e quella «finito» (spunta o brillantini).
3. **Icona**: l'emoji o icona attuale.

Altre regole:
- Il default sono le animazioni della plancia per i tipi riconosciuti.
- Nel foglio ✏️ c'è l'anteprima dal vivo.
- Le scelte si salvano nel layout.
- Le stesse immagini compaiono in Home e nella mappa.
- Rispetta `prefers-reduced-motion`.
- Il pacchetto resta leggero.
