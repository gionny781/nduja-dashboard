# 0.7.36-dev — Rete e server
Prima: `0.7.35-dev` · File in più: pages/aggiornamenti.js, pages/dispositivi.js, core.js, app.js

Nuova pagina **«🌐 Rete»**. Compare solo se trova qualcosa.

## A) Internet
- Stato della connessione.
- Velocità in tempo reale (download/upload) dal modem/router.
- IP pubblico, se esposto.
- Ultimo speedtest (integrazione Speedtest.net) con grafico, e pulsante «Prova adesso».
- Le integrazioni da riconoscere sono le più comuni: Fritz!Box, UniFi, TP-Link Omada/Deco, Mikrotik, OpenWrt (luci), Netgear, Asus router, Huawei LTE, Vodafone Station, Sky WiFi, ecc. Usa i sensori standard (device_class data_rate, data_size, connectivity).

## B) Dispositivi e server
Schede per modem/router, mini PC, NAS, Proxmox, Raspberry, stampanti, con:
- acceso/spento (ping o connettività);
- CPU, RAM, disco e temperatura (System Monitor, Glances, Proxmox VE, Synology DSM, TrueNAS…);
- uptime;
- pulsanti di riavvio/accensione se l'integrazione li ha (button/switch, Wake on LAN), con doppia conferma.

## C) Dispositivi collegati
- Numero di dispositivi online (device_tracker del router).
- Elenco dei nuovi dispositivi visti oggi (utile per sicurezza).
- Ospiti/Wi-Fi ospiti on/off se disponibile, con QR code del Wi-Fi ospiti disegnato da un generatore QR **scritto da te** (nessuna libreria esterna).

## D) UPS
Se c'è un gruppo di continuità (NUT, APC UPS Daemon):
- carica;
- autonomia;
- carico;
- stato rete/batteria.

## E) Configurazione
Tutto automatico, con ✏️ per aggiungere, togliere o rinominare dispositivi e scegliere i sensori. In Home una scheda compatta «Rete» con internet ok/ko, velocità e server spenti.
