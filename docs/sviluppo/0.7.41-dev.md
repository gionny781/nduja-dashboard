# 0.7.41-dev — Guida all'installazione illustrata
Prima: `0.7.40-dev` · File in più: README.md, docs/*.png, tools/mock

Ultimo passo prima della 0.8.0 ufficiale: una guida chiara, per chi non è esperto.

## A) `COME_INSTALLARE.md` (italiano) e `HOW_TO_INSTALL.md` (inglese)
Passo per passo, ognuno con uno screenshot:
1. installare HACS (link alla guida ufficiale);
2. aggiungere il repository personalizzato;
3. scaricare 'Nduja;
4. riavviare Home Assistant;
5. aggiungere l'integrazione;
6. aprire 🌶️ 'Nduja;
7. la procedura guidata, Automatica o Manuale.

Poi due capitoli:
- **Prepara la casa**: aree, piani, persone con il telefono, configurazione Energia. Spiega perché servono e dove si trovano in Home Assistant.
- **Problemi frequenti**: schermata bianca (rimanda a «Controlla Home Assistant»), dispositivi che non compaiono, telecamere senza diretta (go2rtc), notifiche che non arrivano (app ufficiale), anteprime e versioni beta in HACS.
