# 0.7.40-dev — Scadenze e promemoria
Prima: `0.7.39-dev` · File in più: pages/liste.js (0.7.39), pages/calendario.js, pages/home.js, avvisi.js, app.js

Nuova pagina **«⏰ Scadenze»**: bollette, tagliando e revisione, assicurazione, bollo, visite, compleanni, abbonamenti, garanzie…

## A) Dove si salvano
- Una lista `todo` di Home Assistant scelta dall'utente (consigliata una Local To-do «Scadenze»), con `due_date`/`due_datetime`.
- Ripetizione e categoria vanno codificate nella descrizione in modo leggibile, così i dati restano in Home Assistant e si vedono anche nelle sue app.
- Se non esiste nessuna lista adatta, un pulsante «Crea la lista Scadenze» spiega come crearla con un tocco: config flow local_todo, se disponibile via websocket; altrimenti istruzioni chiare.

## B) Pagina
- Gruppi: **Scadute**, **Oggi**, **Prossimi 7 giorni**, **Più avanti**.
- Categorie con icona: bollette, auto, casa, salute, documenti, abbonamenti, altro.
- Ripetizione: nessuna, settimanale, mensile, ogni N mesi, annuale. Con «Fatto», la prossima scadenza si calcola da sola.
- Importo facoltativo (es. bolletta 82 €) e totale del mese.

## C) Promemoria
- Notifica sul telefono (`notify.mobile_app_*` delle persone scelte) con anticipo selezionabile: il giorno stesso, 1, 3 o 7 giorni prima, a un'ora scelta.
- Lo fa un'automazione «'Nduja · scadenze» creata dalla plancia, con etichetta «'Nduja».
- La notifica ha le azioni «Fatto» e «Ricordamelo domani».

## D) Home e avvisi
- Scadenze di oggi e scadute nella scheda Avvisi.
- In Home la scheda «Scadenze» con le prossime 3.
