# 0.7.40-dev — Piante e giardino
Prima: `0.7.39-dev` · File in più: pages/irrigazione.js (0.7.25), pages/aria.js (0.7.37, per lo stile), avvisi.js, app.js

Nuova pagina **«🪴 Piante»**. Compare se ci sono entità `plant.*`, sensori per piante (Xiaomi Mi Flora, Plant Monitor da HACS, sensori di umidità del terreno), oppure se l'utente aggiunge piante a mano.

## A) Le mie piante
- Una scheda per pianta: nome, stanza, foto scattata o caricata dall'utente (nei Media o `/local/`). Niente immagini da internet.
- Illustrazione disegnata da te per tipo: pianta verde, grassa, fiorita, aromatica, orto, albero.

## B) Sensori
Quando ci sono, mostra con barre e soglie (dalle entità `plant` o scelte dall'utente):
- umidità del terreno;
- luce;
- temperatura;
- fertilità/conducibilità;
- batteria del sensore.

Stato in parole semplici: «Ha sete», «Troppa luce», «Tutto ok».

## C) Promemoria senza sensori
Per le piante senza sensore:
- «Annaffia ogni N giorni» e «Concima ogni N settimane»;
- pulsante «Fatto oggi»;
- dati nello Store condiviso `casa` della 0.7.14 (tutti gli utenti possono segnarlo);
- promemoria nella scheda Avvisi e, facoltativamente, sul telefono.

## D) Giardino
- Collegamento con l'Irrigazione (0.7.25): se una zona irriga le piante, il «Fatto» si segna da solo.
- Se domani piove, il promemoria per l'esterno slitta.
